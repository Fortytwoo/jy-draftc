# 混剪与多层画面

先加载 `yoyoking-edit`。读取素材信息并观察候选源画面，按照用户目标写出简短镜头表：源文件、source_in、source_duration、speed、时间线 start、画面层级和声音用途。不要虚构未观察到的镜头，也不要为了凑目标时长拉伸超出素材边界。

1. 创建工程和主 video 轨道。逐镜调用 `add_video_clip`，时间线时长按 source_duration/speed 计算，下一个镜头 start 累加前面时长。相邻镜头不靠重叠模拟转场。
2. 删除停顿时先计算需要保留的源区间，可通过 `split_clip`、`remove_clip`、`trim_clip`、`move_clip` 完成。带关键帧、转场、淡入淡出或片段动画的片段必须先清除相关设置才能分割；分割后重新建立需要的动画。
3. 配合 `set_clip_speed` 重算后续镜头位置。服务工程只支持恒速；删除镜头可用 `remove_clip(ripple=true)` 同轨平移。已有原生工程可用 `set_native_clip_speed` 的预设/自定义曲线，以及 `remove_native_clip(ripple=true)`，每次都在新副本操作；曲线变速不自动平移后续镜头，跨轨音频/字幕不会自动同步。读取最新工程确认空隙和冲突。
4. 画中画创建上层 video 轨道，添加视频或图片到对应时间范围，再设置 scale_x/scale_y 和 x/y。contain 保留内容，cover 裁满画幅。根据画面观察选择，不凭参数声称人脸或产品未被裁切。
5. 推近/平移使用 `set_keyframes`，分别配置 scale_x、scale_y 或 x/y 属性，点位使用片段相对秒数。只支持线性插值。
6. 转场调用 `list_transitions` 后选择返回的准确名称，设置在出场片段上，相邻片段需要满足工具校验。能列出名称不表示目标环境资源已经通过画面验收。
7. 需要配乐时建立 audio 轨道，先检查是否已有原声，明确保留、静音或降低哪条声音。`set_clip_audio` 同时带上音量和需保留的淡入淡出。

需要裁剪区域、原生动画、画面/人物特效、滤镜、独立效果轨道、形状蒙版、色度抠图、混合模式、背景填充、贴纸和音效时，按需读取 yoyoking-edit 的 `references/advanced-editing.md`。选定资源后以独立功能工具组合，避免把一套混剪流程固化为一个调用。已有本地模板可按片段或名称换料，也可复制轨道；变速片段换料不受支持，先说明限制并按实际素材重建所需片段。

回读完整时间线，然后按 `yoyoking-edit` 保存快照和导出。观察开头、镜头衔接、画中画出现/结束和结尾；只对实际观察到的范围描述画面结果。用户修改某一个镜头时定位 clip_id 做增量返修。
